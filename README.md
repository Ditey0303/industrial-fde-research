# IFDE Research Doc — 工业 FDE 研究存档

围绕 **工业场景的 FDE（Forward Deployed Engineering）** 的公开资料研究与实测核验存档。

作者定位：十年工业 PLC 工程师 × AI 交付。研究的问题只有一个——**AI 进入工厂的最后一公里，谁来做、怎么做、怎么收钱。**

## 为什么是工业域

FDE 的公开案例库正在快速膨胀（范冰《前线部署工程师》165 案、Anthropic 官方案例、各类独立 FDE 服务商），但截至 2026-09 检索，**制造业案例接近空白**：现有案例集中在软件/法律/金融/租赁/政务，工业现场——产线、电耗、协议、停线成本——无人系统化记录。

这不是因为工业不需要，而是因为做 FDE 研究的人大多不在现场，在现场的人大多不做研究。本存档从这个缺口进入。

## 证据原则（比通用研究存档更严）

1. **只引一手源**：官方文档、官方 JD、年报原文、标准文本，不采用媒体转述
2. **现场实测优先**：工业领域，一台电表的实测读数 > 厂商手册 > 行业报告。本存档的实测数据均标注实测日期与工况
3. **事实与推断分层**：每条结论标注【事实】（可直接核验）/【推理】（多源归纳）/【待现场确认】（需工程师在产线环境核验）
4. **不冒充**：不把 IT 实施工程师、自动化集成商、转型顾问自动称为 FDE
5. **引用别人的研究必须署名**：综合他人存档时注明来源与日期，方便读者自行复核

## 更新节奏

- 每周日增量更新（与 FDE 全球监测扫描联动，工业子集自动入档）

## 使用说明

这份存档有三个用途：
1. **作品集**：展示"证据分级研究 × 工业现场经验"的复合能力
2. **交付前置品**：协议适配核验 = 数据接入类 POC 的第一份交付物原型
3. **弹药库**：案例追踪表 = 客户对话中的"我知道行业里谁在做"底牌
